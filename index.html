Bifrost

A private hub for every device on your Wi-Fi.

Bifrost turns one machine on your network into a hub for every phone, tablet and laptop in the house — no cloud, no accounts. Send files between devices, share a clipboard, and open a full workbench of developer tools. The browser tools are live on the web, too.

  • Files and clipboard sync across devices, live over SSE
  • Editors for JSON, YAML, XML/plist, Markdown and JavaScript, a JSON diff, and 15 everyday utilities
  • A CLI, OpenAPI docs and an optional Grafana observability stack
  • Runs natively on a Mac, or on a Raspberry Pi with Docker

Node.js · TypeScript · Fastify · React · SQLite · Docker

How I work

  1. 01

    Own it end to end

    From the first line of code through QA, release, and the monitoring and scaling after launch.

  2. 02

    Architecture sized to the problem

    VIPER, MVVM or Clean Architecture — picked for the team and the codebase, without ceremony a three-screen app doesn't need.

  3. 03

    Networks that hold up

    mTLS, retry and failover, real-time channels with a fallback, offline-first sync and payloads cut down to size.

  4. 04

    Ship with confidence

    CI/CD on every change, crash reporting in production, and tests that run against the real thing.
